# Arthur Monserrat Portfolio

> **Status:** Sprint 01 concluída localmente. Publicação pendente de repositório remoto e deploy.

Portfólio profissional de Arthur Monserrat Souza, estudante de Engenharia de Software. Este projeto é a entrega do LAB01 de DIAW e apresenta uma trajetória em construção com foco em projetos reais e contatos verificáveis.

## Sprint 01 — planejamento e prototipação

- Tecnologias previstas: React, Vite, JavaScript, CSS puro, EmailJS, Vercel e Vitest.
- Estrutura inicial: página única com cabeçalho, navegação por âncoras, hero, Sobre Mim, Projetos, Experiências, Contato e rodapé.
- Direção visual: estética editorial técnica com azul-noturno, texto claro, verde-lima, numeração e timeline vertical.
- Wireframes de média fidelidade: [arquivo Figma](https://www.figma.com/design/AP1vCzHXem9UYPc8woX1aO) e capturas em `docs/wireframes/`.
